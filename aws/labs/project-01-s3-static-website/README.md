# Project 01 - Static Website Hosting on AWS S3

## Overview

This project demonstrates how to host a static website using Amazon S3.

The website is deployed using Amazon S3 Static Website Hosting and is publicly accessible through the S3 website endpoint.

## AWS Services Used

- Amazon S3
- S3 Static Website Hosting
- Bucket Policy

## Skills Practiced

- Creating an S3 bucket
- Uploading website files
- Configuring static website hosting
- Managing bucket permissions
- Deploying a public website
